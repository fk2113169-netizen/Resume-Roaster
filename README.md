# 🚀 AI Resume Roast

An uncompromising, AI-driven development suite designed to audit, evaluate, and brutally roast professional resumes. This application bypasses generic resume feedback patterns to analyze layout structures, sentence velocity, and keyword densities—ensuring applicants stand out to both automated ATS parsers and human technical recruiters.

**🔗 Live Production Deployment:** [ai-resume-roast.vercel.app](https://ai-resume-roast.vercel.app)

---

## 🛠️ Built With

The architecture utilizes modern, ultra-fast web frameworks and edge runtime environments:

* **Frontend Framework:** [Next.js](https://nextjs.org/) (React Framework for the Edge)
* **Styling Suite:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first styling for fluid UI/UX layouts)
* **Core Logic Engine:** Built using code configurations optimized with Antigravity
* **Hosting & CI/CD:** Deployed natively via the [Vercel CLI Platform](https://vercel.com/)

---

## 🔥 Key Features

* **Rigorous Metric Analysis:** Breaks down passive wording, weak sentence structures, and lack of quantifiable achievements using custom rule-based heuristics.
* **ATS Compatibility Evaluation:** Identifies fatal layout bugs (such as complex tables, hidden headers, or non-indexable graphics) that cause parsing errors in corporate software.
* **Production-Ready Optimization:** Leverages optimized build strategies to deliver dynamic feedback seamlessly under one second.
